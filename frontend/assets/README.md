# Логотип

Положите файл логотипа сюда под именем `logo.png`:

```
frontend/assets/logo.png
```

После этого обновите страницу — логотип появится в боковой панели, на странице
входа и во вкладке браузера. Пока файла нет, показывается стандартный значок,
интерфейс при этом не ломается.

## Требования к файлу

- Формат: PNG с прозрачным фоном (лучше всего), SVG, JPG или WebP.
- Пропорции: квадрат — знак вписывается в квадратную область.
  Широкий логотип с текстом «сожмётся», поэтому лучше использовать только знак,
  а название задать отдельно (см. ниже).
- Размер: от 128×128 до 512×512 пикселей.

## Другое имя или формат

Имя файла задаётся в `frontend/js/config.js`:

```js
window.APP_CONFIG = {
  logo: 'assets/logo.svg',   // путь к вашему файлу
  appName: 'Ali Trade',      // название рядом с логотипом и в заголовке вкладки
};
```

Значок вкладки берётся из `assets/logo.png` — если файл называется иначе,
поправьте `<link rel="icon" href="assets/logo.png" />` в HTML-страницах.
