# Адверсариальные тесты фронтенда

Тесты доказывают конкретные поломки в `frontend/js/**` и `frontend/css/**`.
Исходники фронтенда не менялись — только читаются.

## Запуск

```
node tests/frontend/run-all.mjs
```

Из корня проекта. Ничего ставить не нужно: только Node (проверено на v24.18.0),
никаких npm-зависимостей.

Код возврата `1` означает, что поломки воспроизвелись (это ожидаемый результат
на текущем коде). Код `0` будет означать, что их починили.

Отдельный сценарий:

```
node tests/frontend/03-admin-only-bypass.test.mjs
```

## Как устроено

Настоящие ES-модули из `frontend/js/**` импортируются в Node поверх минимального
DOM (`helpers/mini-dom.mjs`): узлы, подмножество CSS-селекторов, `classList`,
`dataset`, события со всплытием, `MutationObserver`, управляемый из теста
`IntersectionObserver`, `localStorage`, `matchMedia`, `FormData`.
Разметка берётся из настоящих `frontend/*.html`, стили — текстом из
`frontend/css/styles.css`.

Семантика `<select>` смоделирована как в браузере: присваивание `select.value`
меняет только IDL-свойства и не порождает ни события `change`, ни записей
`MutationObserver`. На этом держится тест 02.

Каждый файл запускается отдельным процессом: тесты подменяют глобальные
`document` / `localStorage` / `fetch`. Штатный `node --test` не используется —
подмена глобального `Event` ломает его протокол обмена с дочерним процессом.

В каждом файле есть тест с пометкой `КОНТРОЛЬ` — он проходит и показывает, что
ломает именно разбираемое условие, а не заглушка DOM.

## Что доказывает каждый файл

| Файл | Поломка |
| --- | --- |
| `01-init-layout-no-cached-user` | Нет `delivery.user` в localStorage → верхняя панель не рисуется: нет бургера (на телефоне меню недостижимо), нет поиска, нет темы, ни одна иконка не подставлена |
| `02-select-value-desync` | `select.value = …` не обновляет подпись кастомного списка: `deliveries.html?state=overdue` показывает «Все», карточка администратора — роль «Сотрудник» |
| `03-admin-only-bypass` | `/auth/me/` не ответил → `adminOnly` не проверяется, `initLayout` возвращает роль из localStorage |
| `04-api-refresh-errors` | Обрыв связи во время refresh отдаёт наружу системный `TypeError`; 401 без refresh-токена не чистит сессию и не уводит на вход |
| `05-deactivated-user-blank-page` | Заблокированный сотрудник получает пустую страницу без сообщения и без редиректа, сессия остаётся |
| `06-motion-hides-painted-content` | `revealIn` после ответа сервера гасит уже отрисованный контент (`data-reveal="out"` → `opacity: 0`) |
| `07-offcanvas-menu-focus` | Закрытое мобильное меню остаётся в порядке обхода Tab; при открытии фокус внутрь не переводится |

Тесты 06 и 07 доказывают проверяемую часть (значения атрибутов и правила CSS);
полное визуальное подтверждение требует настоящего браузера.
